Privacy Policy

Hermes — personal automation client · Effective November 12, 2026

This policy explains how Hermes ("the app"), a single-user private desktop client operated by its owner, handles data obtained through Google APIs.

1. Who this applies to

The app has exactly one authorised user: the account owner who completed the OAuth consent flow. There are no other users, accounts, or customers. The app is not a hosted or multi-tenant service.

2. What data the app accesses

Only after the owner grants consent, and only for the owner's own account, the app may access:

  • Gmail — read message metadata and bodies, and send or draft mail when the owner asks
  • Google Calendar — read and create or delete events on the owner's calendars
  • Google Drive — read, create, update, share or trash the owner's own files
  • Google Docs — read the contents of the owner's documents and append text when asked
  • Google Sheets — read and write cells in the owner's spreadsheets
  • Google Contacts — read the owner's contact names, emails and phone numbers

These correspond to the OAuth scopes requested at consent time. The app makes no attempt to access data belonging to anyone other than the owner.

3. How data is stored and retained

  • OAuth credentials (access and refresh tokens) are stored in a local file on the owner's own computer, at ~/.hermes/google_token.json, readable only by that machine's user.
  • Retrieved content is processed in memory on the owner's device. Some results may be cached in local files on that device to support the owner's workflow.
  • No Google user data is uploaded to any server operated by the app, because the app operates no servers. Nothing is retained beyond what is written to the owner's local disk.

4. Sharing and disclosure

The app does not sell, rent, trade, or share Google user data with third parties. It does not use Google user data for advertising, profiling, or model training. Data leaves the owner's device only when the owner explicitly instructs an action (for example, sending an email) or when a request is made to Google's own APIs to fulfil that action.

5. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the features the owner requested.

6. Revoking access and deleting data

  • Revoke the app's access at any time at myaccount.google.com/permissions.
  • Delete local credentials by removing ~/.hermes/google_token.json on the owner's machine.
  • Any cached local files can be deleted by the owner at any time; they are ordinary files on the owner's disk.

7. Security

Credentials are stored locally and transmitted only to Google's OAuth and API endpoints over HTTPS. The app requests the minimum scope set needed for the features the owner uses and does not store credentials in any remote location.

8. Children

The app is a personal tool for its owner and is not directed at children under 13.

9. Changes

If this policy changes, the revised version will be published at this URL with a new effective date.
